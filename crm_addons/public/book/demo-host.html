Book a demo: embed examples

This sample page is a stand-in for one of your websites. Copy the snippets below into your own pages.

1. Install once (before </body>)

<script src="https://CRM-HOST/assets/crm_addons/book/embed.js" async></script>

It also remembers where the visitor came from (UTM tags, ad click ids, referrer) for 30 days, so every booking in the CRM carries its campaign.

2. A button

<button data-crm-demo="SLUG">Book a demo</button>

3. A link

Book a free demo class (opens the pop-up; middle click still opens the plain booking page)

<a data-crm-demo="SLUG" href="https://CRM-HOST/book/SLUG">Book a free demo class</a>

4. Inline in the page

<div data-crm-demo-inline="SLUG"></div>

5. From your own JavaScript

CRMDemo.open('SLUG', { prefill: { name: 'Asha', email: 'asha@example.com', phone: '9876543210' }, utm: { utm_source: 'newsletter' } })
